# 📱 Teleprompter (Телесуфлёр для iPhone)

Ультра-плавный, минималистичный веб-суфлёр, оптимизированный в первую очередь под мобильный Safari на iOS и съёмку видео со смартфона.

Сайт открывается на втором телефоне, который устанавливается прямо под объектив основной камеры — в результате взгляд спикера всегда направлен точно в объектив!

---

## ✨ Основные возможности

- **100% автономный:** Всё приложение собрано в одном чистом файле `index.html` (HTML5, современный CSS3, Vanilla JS без точек с запятой и сборщиков).
- **Плавный скролл (60–120 FPS):** Реализован на `requestAnimationFrame` с дробным субпиксельным аккумулятором — текст едет плавно даже на минимальной скорости.
- **Интеллектуальная пауза и свайп:** Касание экрана мгновенно ставит прокрутку на паузу и возвращает панель управления. Можно листать текст вручную в любой момент.
- **True Black (#000000) для OLED:** Идеально для тёмных помещений — экран не засвечивает лицо оператора и бережёт заряд аккумулятора.
- **Зона взгляда (Eye-line Guide):** Направляющая линия со стрелками в верхней трети экрана (28vh), чтобы взгляд был максимально близко к объективу камеры смартфона.
- **Двойной Wake Lock (экран не гаснет):** Официальный Screen Wake Lock API + видео-фоллбэк для Safari iOS с авто-возобновлением при возврате во вкладку.
- **Поддержка чёлки и Dynamic Island:** Корректный учёт `env(safe-area-inset-top)` и `env(safe-area-inset-bottom)`.
- **Зеркальный режим (Horizontal Flip):** Для профессиональной съёмки через полупрозрачное стекло (beam-splitter glass).
- **Таймер обратного отсчёта:** Выкл / 3 секунды / 5 секунд с пульсирующей анимацией, чтобы успеть занять позицию в кадре.
- **Полное сохранение состояния:** Текст, скорость, размер шрифта, ширина колонки, таймер и **точная позиция скролла** сохраняются в `localStorage`. При случайной перезагрузке вы продолжите с того же места!

## 📲 Как установить на iPhone как отдельное приложение (PWA)

1. Откройте ссылку на суфлёр в браузере **Safari** на iPhone.
2. Нажмите на иконку **«Поделиться»** (квадрат со стрелкой вверх внизу экрана).
3. Пролистайте вниз и выберите пункт **«На экран "Домой"»** (*Add to Home Screen*).
4. Нажмите **«Добавить»**.
5. На рабочем столе появится иконка суфлёра — при открытии приложение работает **в полноэкранном режиме без адресной строки Safari**!

## 🚀 Как запустить локально или развернуть

### 1. Локальный запуск за 5 секунд

Так как это чистый HTML/JS файл, вы можете запустить любой локальный сервер:

```bash
# Вариант 1 (Python):
python3 -m http.server 8080

# Вариант 2 (Node.js npx):
npx serve .
```
Откройте `http://localhost:8080` (или IP вашего компьютера в локальной сети Wi-Fi, чтобы сразу открыть на iPhone).

---

### 2. Деплой на Vercel (Бесплатно)
1. Установите Vercel CLI (если не установлен): `npm i -g vercel`
2. В папке с проектом выполните команду:
   ```bash
   vercel
   ```
3. Через 10 секунд вы получите готовую публичную `https://...` ссылку.

---

### 3. Деплой на GitHub Pages (Бесплатно)
1. Создайте репозиторий на GitHub и загрузите `index.html`.
2. Перейдите в **Settings** -> **Pages**.
3. В разделе **Source** выберите ветку `main` и папку `/ (root)`.
4. Нажмите **Save**. Сайт будет доступен по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## ⌨️ Горячие клавиши (для тестов на ПК/Mac)

- **Пробел (Space):** Старт / Пауза.
- **Стрелки Вверх / Вниз:** Быстрая прокрутка текста назад / вперёд.
- **Escape:** Закрыть панель настроек или поставить на паузу.
